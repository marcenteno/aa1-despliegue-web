# AA1 - Despliegue de Aplicaciones Web

**Ciclo:** 2.º DAW  
**Curso:** 2026/2027

## Descripción

Repositorio correspondiente a la actividad AA1 de Despliegue de Aplicaciones Web. En él se recoge el desarrollo y despliegue de las distintas prácticas realizadas durante las cuatro fases del ejercicio.

## Fases del proyecto

### Fase 1 - Despliegue MERN en EC2
Despliegue de una aplicación MERN (MongoDB, Express, React y Node.js) en una instancia EC2 de AWS.

### Fase 2 - Despliegue con Docker Compose
Despliegue de la aplicación utilizando contenedores y Docker Compose.

### Fase 3 - Publicación web con dominio y HTTPS
Publicación de un sitio web en AWS mediante un servidor web, configuración de dominio y certificado HTTPS.

### Fase 4 - Despliegue de Odoo multirregión
Despliegue de Odoo en dos regiones de AWS y configuración de acceso mediante una zona privada de Route 53.

## Estructura del repositorio

- `fase1-mern-ec2/`: aplicación MERN, documentación, scripts y evidencias.
- `fase2-docker-compose/`: archivos y documentación de la segunda fase.
- `fase3-dominio-https/`: archivos y documentación de la tercera fase.
- `fase4-odoo-multiregion/`: archivos y documentación de la cuarta fase.

## Tecnologías utilizadas

AWS, EC2, Ubuntu, Node.js, MongoDB Atlas, Nginx, Docker, Docker Compose y Odoo.
